# Online Store

An online store project built to support online shopping.

## Overview

This project is a general online store where users can browse products, add items to their cart, and place orders.

It includes the main features of an online shopping system, such as user accounts, product management, orders, and payments.

The project also includes database design and technical documentation.


## Features

- User registration and account management
- Product and category management
- Product images and color options
- Shopping cart with guest user support
- Address management
- Order and order item management
- Payment tracking
- Product reviews and ratings

## Database Design

The database is designed around the following main entities:

- User
- Category
- Product
- Color
- ProductImage
- Cart
- CartItem
- Address
- Order
- OrderItem
- Payment
- Review

The database design and entity relationships are documented using ERD diagrams.
